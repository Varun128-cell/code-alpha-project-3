# 🎯 Smart Human Tracker

An AI-powered web app that tracks people in uploaded videos using YOLOv8 for object detection and DeepSORT for real-time identity tracking. Visual modes include **Normal**, **Thermal**, and **Blurred** to enhance the viewing experience.

## 🚀 Features

- 🧍‍♂️ Detects and tracks humans using YOLOv8 + DeepSORT
- 🟦 Highlight people with bounding boxes and track IDs
- 🌡️ Thermal view mode for simulation-style visuals
- 🔲 Blur mode for anonymization or privacy effects
- 📼 Supports most video formats (MP4, AVI, MOV)
- 🌐 Intuitive web interface built with Streamlit
